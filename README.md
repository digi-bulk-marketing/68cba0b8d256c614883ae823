# Button Sender Lite

Button Sender Lite by BITBEAST PRIVATE LIMITED.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/68cba0b8d256c614883ae823/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Button Sender Lite** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/68cba0b8d256c614883ae823/releases/latest) and reinstall.
